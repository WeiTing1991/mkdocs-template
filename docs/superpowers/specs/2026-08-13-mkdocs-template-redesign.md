# MkDocs Template Redesign -- Zensical + Multi-Language Support

**Date:** 2026-08-13
**Status:** Approved

## Goal

Redesign the existing `mkdocs-template` repo from a bare-bones MkDocs setup to a modern documentation template using Zensical (the successor to MkDocs + Material), managed with uv, supporting Python, C++, and C# documentation including auto-generated API references.

## Context

- MkDocs 1.x is unmaintained (no releases since Aug 2024)
- MkDocs 2.0 removes the plugin system, breaks all existing plugins
- Material for MkDocs is in maintenance mode (EOL Nov 2026)
- Zensical (MIT, by the same team) is the designated successor -- Rust core, drop-in compatible, reads `mkdocs.yml` natively

## Decisions

- **Engine:** Zensical (primary), with a backward-compatible `mkdocs.yml` included as fallback
- **Package manager:** uv (all deps are PyPI packages, no need for pixi/conda)
- **Branching:** Single branch, single template with language sections (delete what you don't need)
- **README:** Only documents Zensical workflow (`zensical serve` / `zensical build`), not MkDocs

## Configuration

### zensical.toml (primary)

- Site name, nav structure with language sections
- Material theme with dark/light toggle
- Search enabled
- Plugins: mkdocstrings (Python), mkdoxy (C++/Doxygen)
- Markdown extensions: pymdownx.highlight, pymdownx.superfences, pymdownx.tabbed, admonition, toc with permalinks

### mkdocs.yml (fallback)

- Equivalent config in MkDocs YAML format
- Uses mkdocs-material theme
- Same plugins and extensions
- Exists for backward compatibility only

## API Documentation Strategy

| Language | Tool | How it works |
|----------|------|-------------|
| Python | mkdocstrings | Reads Python docstrings, generates API reference in-place |
| C++ | MkDoxy | Runs Doxygen on C++ source comments, converts XML to markdown |
| C# | MkDoxy | Runs Doxygen on C# source comments, converts XML to markdown |

### Python -- mkdocstrings

mkdocstrings reads Python docstrings directly. In `docs/python/api.md`, you use the `::: module.path` directive and it auto-generates the reference.

Example source (`src/example.py`):
```python
def add(a: int, b: int) -> int:
    """Add two numbers.

    Args:
        a: First number.
        b: Second number.

    Returns:
        The sum of a and b.
    """
    return a + b
```

Example `docs/python/api.md`:
```markdown
# Python API Reference

::: src.example
    options:
      show_source: true
      heading_level: 2
```

### C++ -- MkDoxy (Doxygen)

MkDoxy runs Doxygen on C++ source files with Doxygen-style comments (`///` or `/** */`), converts the XML output to markdown, and embeds it in your docs.

Example source (`src/example.hpp`):
```cpp
/// @brief Add two numbers.
/// @param a First number.
/// @param b Second number.
/// @return The sum of a and b.
int add(int a, int b) {
    return a + b;
}
```

Example `docs/cpp/api.md` using MkDoxy snippet syntax:
```markdown
# C++ API Reference

::: doxy.example
    :src: src/
    :doc: C++ API
```

MkDoxy config in `mkdocs.yml` / `zensical.toml`:
```yaml
plugins:
  - mkdoxy:
      projects:
        example:
          src-dirs: src/
          full-doc: true
```

### C# -- MkDoxy (Doxygen)

Doxygen also supports C# via XML documentation comments (`///`). MkDoxy processes these the same way as C++.

Example source (`src/Example.cs`):
```csharp
/// <summary>
/// Add two numbers.
/// </summary>
/// <param name="a">First number.</param>
/// <param name="b">Second number.</param>
/// <returns>The sum of a and b.</returns>
public static int Add(int a, int b)
{
    return a + b;
}
```

Example `docs/csharp/api.md`:
```markdown
# C# API Reference

::: doxy.Example
    :src: src/
    :doc: C# API
```

MkDoxy config adds the C# project alongside C++:
```yaml
plugins:
  - mkdoxy:
      projects:
        cpp_example:
          src-dirs: src/cpp/
          full-doc: true
        csharp_example:
          src-dirs: src/csharp/
          full-doc: true
```
